# Building TravelerHub as a Native App

## Prerequisites
- Node.js 18+
- For iOS: macOS with Xcode 15+ and Apple Developer account ($99/year)
- For Android: Android Studio with SDK 33+

## First-time setup
```bash
npm install
npx cap add ios      # Creates ios/ directory
npx cap add android  # Creates android/ directory
```

## Development (live reload on device)
Make sure your phone and computer are on the same WiFi.
Update capacitor.config.ts server.url to your computer's local IP (e.g. http://192.168.1.5:5173).
```bash
npm run dev          # Start Vite dev server
npx cap run ios      # Deploy to iOS simulator or connected iPhone
npx cap run android  # Deploy to Android emulator or connected phone
```

## Production build
```bash
npm run cap:ios      # Build + sync + open Xcode (then Archive → submit)
npm run cap:android  # Build + sync + open Android Studio (then Generate Signed Bundle)
```

## App Store notes
- iOS: Requires camera usage description in Info.plist (Xcode adds automatically from plugin config)
- iOS: Requires location usage description for background tracking
- Android: Permissions declared in AndroidManifest.xml (auto-generated by Capacitor)
